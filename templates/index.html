API Coverage

Compare Farm Metadata

Enter farm IDs to compare metadata between OLD DB API and NEW REDIS API

Example: Enter farm IDs separated by new lines or commas

Note: Results are displayed inline in your browser. No files are saved to disk. Processing time depends on number of farms and API response times.

How It Works

Process Flow

  1. Enter farm IDs to monitor
  2. Generate JWT authentication token
  3. Fetch metadata from OLD DB API
  4. Fetch metadata from NEW REDIS API
  5. Compare responses using DeepDiff
  6. Generate reports and display results

Features

  • Compare multiple farms in one request
  • Color-coded difference highlighting
  • Detailed summary statistics
  • Expandable comparison details
  • Real-time status display
  • No files written to disk
